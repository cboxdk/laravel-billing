# Cbox Billing v0.11.0

Cbox Billing v0.11.0 lets quote lines carry fractional quantities, such as 12.5 tonnes or 0.950 hours, and an optional unit such as `t` or `h`. A line's quantity is now a `Quantity` value object with up to three decimals, not an `int`, and each line's amount is computed with `Money::times()`, rounded once, half up, to the currency's minor unit. The unit travels with the line onto the quote, the invoice and any credit note. This release changes a public property type, so consumers of `LineInput` or `QuoteLine` need to read the Breaking section before upgrading.

## Breaking

- `LineInput::$quantity` and `QuoteLine::$quantity` are a `Cbox\Billing\Quote\ValueObjects\Quantity`, no longer an `int`. Code that reads the property as an integer must change. Use `->quantity->toInt()` where a whole-number quantity is meant (for example a seat count). This throws `InvalidQuantity` if the quantity is fractional.
- Amounts must be computed with `Money::times(Quantity)`, not `multipliedBy($int)`. `times()` multiplies and rounds half up once, to the currency's default scale.
- To persist a quantity, store `->quantity->toDecimalString()`, which always returns three decimals (for example `12.500`). Do not store the `int`, because it loses the fraction.
- `LineInput` and `QuoteLine` gain an optional `?string $unit`. Pass the unit when a line has one, and read `->unit` when you render or persist the line. A unit is trimmed, becomes `null` when blank, and may be at most 12 characters.
- `LineInput` still accepts an `int` for quantity this release and converts it to a `Quantity`. The `int` form is removed in the next minor release, so pass a `Quantity` in new code.
- A quantity may not exceed 9999999999999.999, the most a `decimal(16,3)` column holds. `Quantity::of()` and `Quantity::ofScaled()` throw `InvalidQuantity::tooLarge` above that, so an `int` quantity above 9999999999999 that was accepted before now throws. Consumers that expose quantities through an API keep their own, lower limits.
- `InvalidQuoteLine::nonPositiveQuantity()` now takes a `string` argument, not an `int`. A new `InvalidQuoteLine::unitTooLong()` is thrown for units longer than 12 characters.

## Added

- `Cbox\Billing\Quote\ValueObjects\Quantity`: a positive decimal with up to three places, held as an integer count of thousandths. It is built with `Quantity::of()` from an int or a decimal string, `Quantity::ofScaled()`, or `Quantity::one()`. It also offers `toInt()`, `toDecimalString()`, `isWhole()` and `equals()`. Quantities are never rounded on input. Input with more than three decimals is refused.
- `Cbox\Billing\Quote\Exceptions\InvalidQuantity`: thrown for a zero or negative, malformed, too precise, too large, or fractional-used-as-whole quantity.
- `Money::times(Quantity $quantity)`: multiplies an amount by a quantity and rounds half up once, to the currency's default scale (ISK stays in whole units).
- `QuoteLine::$unit` and `LineInput`'s `unit` argument, carried through refunds: a partial refund line uses quantity 1 and carries no unit, while a full refund copies each line's quantity and unit.

## Rounding

A quote line is rounded once per line, half up, to the currency's minor unit. The quote is the sum of its rounded lines, so the amount shown at confirm equals the amount charged.

| Case | Result |
| --- | --- |
| `0.950 × 120000 DKK` | `114000` |
| `1.125 × 100000 DKK` | `112500` |
| `0.333 × 10000 DKK` | `3330` |
| `2.5 × 333 DKK` | `833` (832.5 rounds half up) |
